# Repair Log

A simple web app to keep track of device repairs. Add a client, device, issue and status, update the status as the work moves forward, and delete finished jobs. Data is saved in the browser with localStorage.

## Features

- Add new repairs
- Change the status: Pending, In progress, Done
- Delete repairs
- Data persists after closing the page

## Tech

HTML, CSS and vanilla JavaScript.

## How to use

Download the files and open `index.html` in your browser.
